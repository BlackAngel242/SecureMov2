                    COMMENT UTILISER LE SCRIPT
═══════════════════════════════════════════════════════════════════════

METHODE 1 : CLIC DROIT (Le plus simple)
    1. Clic droit sur SecureMover.ps1
    2. "Executer avec PowerShell"
    3. Accepter privileges administrateur (UAC)
    4. Suivre les instructions a l'ecran

METHODE 2 : TERMINAL
    1. Ouvrir PowerShell en tant qu'Administrateur
    2. Naviguer vers le dossier :
       cd "C:\Users\DrSmoke\projet\Claude\SecureMover"
    3. Executer :
       .\SecureMover.ps1

IMPORTANT : Le script necessite UTF-8 with BOM !
    ├── Dans VS Code / Cursor : voir en bas a droite
    ├── Si different : Clic > Save with Encoding > UTF-8 with BOM
