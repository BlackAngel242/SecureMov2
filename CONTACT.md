## 🤝 Contribuer au Projet

SecureMover est un projet **open-source** ! Toutes les contributions sont les bienvenues.

### Comment Contribuer ?

**Sur GitHub** :
1. 🍴 **Fork** le projet : https://github.com/DrSmoke/SecureMover
2. 🌿 Créez une branche pour votre fonctionnalité : `git checkout -b feature/ma-super-fonctionnalite`
3. ✍️ Faites vos modifications et commitez : `git commit -m "feat: ma fonctionnalité"`
4. 📤 Poussez vers votre fork : `git push origin feature/ma-super-fonctionnalite`
5. 🔀 Ouvrez une **Pull Request** sur le repo principal

**Guide détaillé** : Voir `CONTRIBUTING.md`

### Types de Contributions Acceptées

✅ **Corrections de bugs**
- Tests et rapports de bugs détaillés

## 🐛 Signaler un Bug

**GitHub Issues** : https://github.com/DrSmoke/SecureMover/issues

Quand vous signalez un bug, merci d'inclure :

1. **Version de SecureMover** : (ex: 2.0.2)
2. **Version de Windows** : (ex: Windows 11 23H2)
3. **Description du problème** : Ce qui devrait se passer vs ce qui se passe
4. **Étapes pour reproduire** : Comment recréer le bug
5. **Logs/Captures d'écran** : Si possible
6. **Fichiers de log** : Exportez le journal d'activité (bouton EXPORTER)

**Template de bug** :
```markdown
## Description
[Décrivez le bug en quelques phrases]

## Étapes pour reproduire
1. Lancer SecureMover-GUI.exe
2. Sélectionner profil "Test"
3. Cliquer sur DÉPLACER
4. [Bug se produit ici]

## Comportement attendu
[Ce qui devrait se passer]

## Comportement actuel
[Ce qui se passe réellement]

## Environnement
- SecureMover: v2.0.2
- Windows: 11 Pro 23H2
- PowerShell: 5.1
```
