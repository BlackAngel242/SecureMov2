                        BUG-001 : DETAILS
════════════════════════════════════════════════════════════════════════

NOM             : Erreur d'encodage emojis
PRIORITE        : P0 - CRITIQUE (bloquant total)
REPORTER        : Test automatique
DATE DECOUVERTE : 2025-01-15 14:40
DATE RESOLUTION : 2025-01-15 14:50
TEMPS RESOLUTION: 10 minutes

DESCRIPTION :
Les emojis Unicode dans la configuration des icones (lignes 76-102)
causaient une erreur de parsing PowerShell. Le fichier n'etait pas
correctement encode, rendant le script totalement inutilisable.

ERREUR ORIGINALE :
---
Au caractere C:\...\SecureMover.ps1:84 : 21
+             user = '��'�'
+                     ~~~~~
Jeton inattendu dans l'expression ou l'instruction.
Le litteral de hachage est incomplet.
---

CAUSE RACINE :
Emojis Unicode (UTF-8 multibyte) mal interpretes par PowerShell lors
du parsing du fichier. Probleme d'encodage lors de la sauvegarde.

SOLUTION IMPLEMENTEE :
Remplacement de TOUS les emojis Unicode par des equivalents ASCII :
