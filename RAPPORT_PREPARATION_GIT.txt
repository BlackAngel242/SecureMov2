                         POINTS D'ATTENTION

⚠️ AUTHENTIFICATION GITHUB :
   Si vous avez une erreur lors du push, créez un Personal Access Token :
   - GitHub > Settings > Developer settings > Personal access tokens
   - Créer token avec scope "repo"
   - Utiliser le token comme mot de passe

⚠️ BRANCH NAME :
   Le repository local utilise 'master'
   GitHub utilise 'main' par défaut
   La commande 'git branch -M main' fait la conversion

⚠️ VÉRIFICATION POST-PUSH :
   Après le push, vérifier sur GitHub que :
   - Tous les fichiers sont présents
