# Politique de Sécurité — SecureMover

## Versions supportées

| Version | Support sécurité |
|---------|-----------------|
| 2.0.2   | ✅ Supportée    |
| < 2.0   | ❌ Non supportée |

## Signaler une vulnérabilité

**Ne créez PAS d'issue publique pour les vulnérabilités de sécurité.**

Pour signaler une vulnérabilité de manière responsable :

1. Ouvrez une **issue privée** via [GitHub Security Advisories](https://github.com/BlackAngel242/SecureMov2/security/advisories/new)
2. Ou contactez l'auteur directement via les [Discussions GitHub](https://github.com/BlackAngel242/SecureMov2/discussions)

### Informations à fournir

- Description de la vulnérabilité
- Étapes pour la reproduire
- Impact potentiel
- Version affectée

### Délai de réponse

- Accusé de réception : sous 48h
- Évaluation initiale : sous 7 jours
- Correction et release : selon la sévérité (24h pour critique, 7 jours pour majeur)

## Bonnes pratiques d'utilisation

- Vérifiez toujours la signature des fichiers téléchargés
- N'exécutez jamais des scripts PowerShell de sources non fiables
- Conservez les sauvegardes `.reg` générées dans un endroit sécurisé
- Utilisez SecureMover uniquement sur des systèmes dont vous êtes propriétaire ou administrateur autorisé
