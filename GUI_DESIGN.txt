═══════════════════════════════════════════════════════════════════════════════
                               INTERACTIONS
═══════════════════════════════════════════════════════════════════════════════

DÉMARRAGE
  1. Chargement automatique des profils utilisateurs
  2. Chargement automatique des disques disponibles
  3. Sélection par défaut du premier élément de chaque liste
  4. Messages de log confirmant initialisation

SÉLECTION DISQUE
  → Mise à jour immédiate de l'indicateur d'espace
  → Changement de couleur selon % disponible
  → Calcul temps réel de l'espace libre

BOUTON DÉPLACER
  → Vérification sélections (profil + disque)
  → Boîte de confirmation avec avertissement
  → Affichage barre progression
  → Logs détaillés de chaque étape
  → Message de succès final
  → Recommandation redémarrage

BOUTON SIMULER (WhatIf)
  → Vérification sélections
  → Affichage simulation dans logs
  → Liste des actions qui seraient effectuées
  → Message clair "AUCUNE MODIFICATION"
  → Boîte d'information finale

BOUTONS RESTAURER/SAUVEGARDER
  → Message "En développement"
  → Promesse version future

═══════════════════════════════════════════════════════════════════════════════
                            STRUCTURE XAML
═══════════════════════════════════════════════════════════════════════════════

<Window>
  <Window.Resources>
    - ModernButton (style de base)
    - AccentButton (bleu)
    - SuccessButton (vert)
    - WarningButton (orange)
  </Window.Resources>

  <Grid> (7 lignes)
    Row 0 : Header (Titre + Sous-titres)
    Row 1 : Sélection Profil
    Row 2 : Sélection Disque + Indicateur
    Row 3 : Boutons Actions (Grid 4 colonnes)
    Row 4 : Barre Progression (masquée par défaut)
    Row 5 : Journal (ScrollViewer + TextBlock)
    Row 6 : Footer (Infos version)
  </Grid>
</Window>

═══════════════════════════════════════════════════════════════════════════════
                          FONCTIONS POWERSHELL
═══════════════════════════════════════════════════════════════════════════════

Write-GUILog          : Ajoute message au journal avec timestamp et type
Show-Progress         : Affiche barre progression avec % et status
Hide-Progress         : Masque barre progression
Get-UserProfiles      : Récupère liste profils C:\Users (exclut systèmes)
Get-AvailableDrives   : Récupère disques disponibles avec stats espace

EVENT HANDLERS
  MoveButton_Click              : Logique déplacement profil
  RestoreButton_Click           : Message "en développement"
  BackupButton_Click            : Message "en développement"
  WhatIfButton_Click            : Simulation WhatIf
  DriveComboBox_SelectionChanged : Mise à jour indicateur espace

Initialize-GUI        : Chargement initial données (profils + disques)

═══════════════════════════════════════════════════════════════════════════════
                               NOTES DESIGN
═══════════════════════════════════════════════════════════════════════════════

PHILOSOPHIE : Minimaliste et Fonctionnel
  - Pas de décorations inutiles
  - Chaque élément a un but clair
  - Hiérarchie visuelle claire (numérotation 1, 2)
  - Espacement généreux pour respiration
  - Feedback immédiat de toute action

INSPIRATION THÈME
  - Visual Studio Code (Dark Theme)
  - Windows Terminal (Dark)
  - Modern Fluent Design
  - Material Design (adapté)

ACCESSIBILITÉ
  - Contrastes élevés (texte blanc sur fond sombre)
  - Tailles de police lisibles (11-32pt)
  - Boutons suffisamment grands (45px hauteur)
  - Curseurs appropriés (main sur boutons)
  - Messages clairs et explicites
